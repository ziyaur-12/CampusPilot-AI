# User Stories
Student

As a student,

I want to upload my resume

So that AI can analyze it.

As a student,

I want AI to suggest better jobs.

So that I can increase my placement chances.

As a student,

I want to track every application.

So I always know my status.

As a student,

I want interview reminders.

So I never miss interviews.

Recruiter

As a recruiter,

I want AI to rank candidates.

So I save time.

As a recruiter,

I want to filter candidates.

So I find better talent.

Admin

As an admin,

I want placement analytics.

So I can monitor college performance.
